# RTB report

Campaign dashboards for RTB flights, published for client review.

Pages are reached by direct link only — there is no index or navigation here, and
every page carries a `noindex` tag with `robots.txt` disallowing the whole host.
That is a request crawlers honour, not access control: the link itself is what
keeps a report private, so share it deliberately.

Each flight lives in its own folder, e.g. `CHC_RTB_2609/`.
